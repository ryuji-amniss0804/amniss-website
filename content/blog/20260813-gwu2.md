家を片づけていると、判断に困る物が必ず出てきます。まだ使えるけれど、自分ではもう使わない。捨てるには大きすぎる。**これ、どこに持っていけばいいんでしょう。**

富山市の場合、その答えは**物によって3つに分かれます**。そして、見る順番が決まっています。順番を間違えると、払わなくてよかったお金を払うことになります。

この記事は、その順番だけを書いたものです。

## まず、それが「家電4品目」かどうか

最初に確認するのはここです。**この4つだけ、ルールがまったく違います。**

- エアコン
- テレビ（ブラウン管・液晶・プラズマ）
- 冷蔵庫・冷凍庫
- 洗濯機・衣類乾燥機

この4つは**町内のごみ集積場に出せません**。富山市は収集しません。家電リサイクル法という別の法律で、行き先が決まっているためです。

方法は3つあります。

**1. 買った店、または買い替える店にお願いする**
リサイクル料金と収集運搬料金を払います。収集運搬料金は店によって違います。

**2. 自分で指定引取場所へ持ち込む**
先に郵便局で家電リサイクル券に記入し、リサイクル料金を振り込みます（別途振込手数料）。券と一緒に指定引取場所へ持ち込みます。**自分で運ぶので、収集運搬料金はかかりません。**

**3. 富山市の有料収集を使う**
こちらも先に郵便局でリサイクル券に記入・振込をします。そのうえで市に収集を申し込みます。**収集運搬料金は1台1,570円**（総額表示）。収集のときに家電リサイクル券を受け取ります。

> **ただし、まだ動く家電なら、次の項目を先に読んでください。**
> 払う前に、受け取れる可能性があります。

## 次に、売れるかどうかを見る

家電4品目に当てはまらない物、そして「まだ動く」家電は、**先に売れるかどうかを見たほうが順番として得です。**

理由は単純で、①の3つの方法も、あとで出てくる市の収集も、**どれもお金を払う側**だからです。売れるなら、お金を受け取る側に回れます。

判断が難しいのは、こういう物です。

- 使えるけれど古い
- 一部が壊れている
- 買ったときは高かったが、今いくらか分からない

**壊れている物も査定します。ただし査定額が0円になった物をお引き取りすることはできません。一般廃棄物収集運搬業の許可がないためです。**

つまり、査定に出しても損はしませんが、**「0円だったのでそのまま持っていってもらう」ということはできません**。0円だった物は、下の「富山市に出す」に進んでいただくことになります。

査定は、**写真を1枚**送っていただければ判断できることがほとんどです。型番が写っていれば、さらに確実です。

→ 出張買取について詳しく: [/kaitori](/kaitori)

## 最後に、富山市に出す

売れない、あるいは売る気がない物は、市の仕組みで出します。ここには**無料で済む道が残っています。**

### 木製の大きい物は、1メートル以内に分解する

タンスや学習机などの木製品は、**1メートル以内に分解すれば「燃やせるごみ」として集積場に出せます。**

大きいから戸別収集を頼むしかない、と思われがちですが、**分解できるなら、まず分解が一番安く済みます。**

### 一辺1メートル以上のスチール製品

パイプベッドや自転車などは、集積場で他のごみと区分して出します。別の車両で収集されます。

### 分解できない、量が多い ——「戸別有料収集」

上のどちらもできない場合は、市の戸別有料収集（予約制）です。

| | |
|---|---|
| 予約先 | 富山市環境センター業務課 **076-428-4040**（予約専用） |
| 受付時間 | 7時45分〜16時30分 |
| **収集日** | **土曜日・日曜日、祝日は収集できません** |
| 料金 | **30kgまで2,090円**。30kgを超える分は10kgごとに319円を加算（総額表示） |
| 出す場所 | 屋外の収集しやすい場所 |
| 立会い | **収集時に立会いと精算が必要です** |

引越しなどでまとまった量が出るときも、この制度が使えます。少量でも収集してもらえます。

**平日の日中に、自分が家にいる必要がある**という点だけ、先に予定を確認しておいてください。ここでつまずく方が多いところです。

## 当社ができること、できないこと

最後に、はっきり書いておきます。

**できること**

- **買取**（古物商許可 富山県公安委員会 第501310007877号）
- **運ぶこと**（貨物軽自動車運送事業 届出済）——引越し、家具・家電の運搬

**できないこと**

**当社は一般廃棄物収集運搬業の許可を受けていないため、廃棄物の有料回収は行っておりません。**

「まとめて持っていってほしい」というご相談は多いのですが、これはお受けできません。許可のない事業者がこれを行うことは、法律で認められていないためです。

だからこの記事を書きました。**当社がお手伝いできない部分は、正しい行き先をお伝えするのが筋だと考えています。**

## 3つの例で、順番を通してみる

**タンス**
→ 家電4品目ではない → 状態がよければ査定に出す価値がある → 売れなければ、**1メートル以内に分解して集積場**へ。分解できなければ戸別有料収集（30kgまで2,090円）

**パイプベッド**
→ 家電4品目ではない → 一辺1メートル以上のスチール製品なので、**集積場で他のごみと区分して出す** → 運び出せなければ戸別有料収集

**洗濯機**
→ **家電4品目**。集積場には出せない → まだ動くなら、まず査定 → 動かないなら、郵便局でリサイクル券に振込 →（買った店 / 指定引取場所へ自分で持ち込み / 市の有料収集1台1,570円）のいずれか
